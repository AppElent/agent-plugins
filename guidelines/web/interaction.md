# Browser interaction

Use semantic controls with accessible names. Keep actions operable by keyboard, provide visible focus, and restore focus sensibly after a dialog closes. Use links for navigation and buttons for actions.

Adapt layout to available width and content length. Check narrow viewports, text zoom, long translations, and both supported themes. Preserve browser scrolling and zoom behavior unless a specific interaction requires a documented exception.

Associate form labels and errors with their fields. Keep invalid values available for correction and make submission results discoverable without depending on color alone.

Preserve useful page content during navigation and background refresh. Pair these browser conventions with the shared UI-state guidelines when those are installed.
