# Review baseline UI

Read the app's docs/guidelines/shared/README.md and relevant general/web sets, then app.md for documented decisions and exceptions. Shared UI standards live in the central guideline source and are deployed locally; use the app's pinned version.

Review the routes affected by the baseline recipe in initial loading, refresh, empty, error, and mutation states. Record route/state/platform, evidence, and exceptions separately from recipe receipts. A component import does not prove the screen behaves correctly.

Verify browser focus, keyboard, zoom, long content, and supported themes. A web viewport fix or PWA install is not native readiness. Use mobile's own procedure and device acceptance when that target is in scope.
