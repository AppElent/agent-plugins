# AppElent Development

App-wide setup and shared capabilities: baseline, authentication, localization, app-user CLIs, the Appelent developer CLI, reusable feature capture, and toolkit maintenance.

Entry points: `/development:feature`, `/development:project`, `/development:dev`, `/development:repo`, and `/development:capture-feature`. Codex also discovers the skills by description.

The plugin chooses and reviews work; `@appelent/dev` performs supported repeatable operations. Install the CLI separately. Shared guideline sets are deployed into the app with the CLI and then read locally.

Web-specific baseline and localization procedures are in the web plugin. Native foundation and device guidance are in mobile. The feature router reports when a required platform skill is unavailable instead of silently assuming another plugin is installed. Runtime packages live in https://github.com/AppElent/appelent-packages.
